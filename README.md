# کاتالوگ خودروها

یک مینی‌پروژه تک‌صفحه‌ای برای مشاهده و فیلتر مشخصات خودروها که با React، TypeScript و Tailwind CSS پیاده‌سازی شده.

## ویژگی‌ها
- دریافت و نمایش دیتا با تاخیر فرضی و مدیریت حالت‌های لودینگ (Skeleton) و ارور
- سرچ بر اساس نام و برند
- فیلتر رنج قیمت
- لایک / علاقه‌مندی‌ها با ذخیره‌سازی در LocalStorage
- مودال جزئیات ماشین با پشتیبانی از بستن با کلید Esc
